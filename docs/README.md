# Documentation Guide

Use this folder as the single source of truth for project docs.

## Start Here

- `QUICK_START.md`: shortest path to run extraction and refresh data.
- `PIPELINE_AND_ROADMAP.md`: end-to-end process and future plan.
- `OPERATIONS.md`: active issue tracker and operational commands.

## Core Conventions

- `DATA_UNITS.md`: currency-unit rules and formatter usage.
- `TICKER_COMPANY_NAME_FIXES.md`: ticker-specific cleanup rules.

## Additional Reference

- `FINANCIAL_STATEMENTS_README.md`

## Doc Hygiene Rules

1. Put actionable "what to run next" content in `OPERATIONS.md`.
2. Keep "how the pipeline works" in `PIPELINE_AND_ROADMAP.md`.
3. Avoid creating one-off status docs; merge updates into existing docs.
4. When a doc becomes stale, delete it instead of leaving conflicting guidance.
